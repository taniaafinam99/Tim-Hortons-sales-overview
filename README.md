# ☕ Tim Hortons Sales Overview Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze sales performance and profitability for Tim Hortons. The dashboard transforms transactional sales data into an interactive business intelligence report that provides an overview of revenue, profit, costs, products, stores, customer types, and payment methods.

The dashboard is designed to help stakeholders monitor overall performance and identify trends and patterns across different business dimensions.

## 🎯 Business Questions

This dashboard aims to answer the following business questions:

* How are revenue, profit, and costs changing over time?
* Which product categories contribute the most to total revenue?
* Which products are the top revenue generators?
* Which stores generate the highest revenue?
* How do new and returning customers contribute to sales?
* Which payment methods are most frequently associated with sales?
* How does sales performance change based on city and category?

## 📊 Dashboard Overview

The dashboard provides an interactive overview of sales performance through key performance indicators, monthly trends, product analysis, store performance, customer type segmentation, and payment method analysis.

Users can interact with the dashboard using filters for:

* Date
* City
* Category
* Customer Type

## 🗂️ Dataset

File: Tim_Hortons_Portfolio_Dataset.xlsx

Rows: ~17,445 transactions

Grain: One row per order line item

| Field | Description |
|---|---|
| `OrderID` | Transaction identifier |
| `OrderDate` | Transaction date |
| `Store` | Store location |
| `Product` | Product name |
| `Revenue` | Total revenue |

The dataset spans stores in Toronto (Downtown & North), Montreal, Vancouver, Ottawa, and Calgary, across five product categories: Coffee, Sandwich, Bakery, Tea, and Desserts.
